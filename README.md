# Tax Calculator — Cloud Native Final Project
 
Static web app served via nginx, containerized with Docker, deployed on IBM Cloud,
and automated through a Tekton CI/CD pipeline.
 
---

```
tax-calculator/

├── spec/
│   └── taxCalculatorSpec.js  
└── tekton/
    ├── tasks.yaml          
    ├── pipeline.yaml       
    └── run.yaml            
```
